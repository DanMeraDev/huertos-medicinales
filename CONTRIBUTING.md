# Cómo contribuir

Antes de crear un issue, una rama o un Pull Request, revisa las reglas del equipo:

1. [Flujo de trabajo con Git](docs/flujo-de-trabajo-git.md): ramas, Pull Requests, revisión y cierre de incrementos.
2. [Estándar de commits](docs/estandar-commits.md): formato de los mensajes y de los títulos de PR.
3. [Estándar de GitHub Issues](docs/estandar-issues.md): tipos, etiquetas, hitos, tablero y definición de terminado.
